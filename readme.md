## 2. Running the Pipeline

Single entry point `main.py` runs all steps end-to-end:

```bash
# Full end-to-end pipeline (CV + final training + predictions + score.py + report):
python main.py

# Fast rerun (skips CV when cv_results.csv and cv_meta.json exist):
python main.py --skip-cv
```

This single command executes:
1. **Cross-Validation**: 3-fold expanding-window temporal CV on `data/train_test.csv`, saving `artifacts/cv_results.csv`, `artifacts/cv_meta.json`, and `artifacts/oof_eval.npz`. Reuses tuned parameters without redundant Optuna re-tuning.
2. **Final Model Training**: Retrains CatBoost on all 48,000 training rows and persists artifacts to `artifacts/`.
3. **Prediction Generation**: Predicts `data/validation.csv` -> `validation_predictions.csv` (12,000 rows) and populates `data/december_chart_inputs.csv` (31 daily rates).
4. **Scorer Validation**: Runs `score.py` to validate formatting and generate `scorer_results/candidate_december.png`.
5. **PDF Report Generation**: Produces `reports/report.pdf` (4 pages, including Error Analysis with out-of-fold diagnostic plots).
6. **Final Checklist**: Validates output constraints.

## 4. Approach & Methodology

### Data Preprocessing
- **Training dataset**: 48,000 loads spanning January–October 2025.
- **Validation dataset**: 12,000 loads spanning November–December 2025.
- **Missing values**: `weight` (~0.6%) and `market_index` (~0.8%) are imputed with training-set medians computed strictly on each training fold to avoid lookahead leakage.
- **Coordinate Lookup**: `CityCoordLookup` derives median pickup and delivery coordinates for each city from the training set; unseen cities fall back to global training medians.

### Validation Strategy
Because validation data is strictly in the future (Nov–Dec 2025), a random K-fold split would leak time-correlated pricing signals. We employ a **3-fold expanding-window cross-validation**:
- **Fold 1**: Train Jan -> Mar 17 (11,998 rows) | Val Mar 18 -> Jun 1 (12,201 rows)
- **Fold 2**: Train Jan -> Jun 1 (24,199 rows) | Val Jun 2 -> Aug 16 (11,968 rows)
- **Fold 3**: Train Jan -> Aug 16 (36,167 rows) | Val Aug 17 -> Oct 31 (11,833 rows)

All encoders, imputers, and target encodings are fitted strictly on each fold's training portion.

### Features & Market Signal Usage
27 engineered features across 5 groups:
1. **Geographic / Route**: Haversine distance, bearing, log distance, distance.
2. **Route Pricing**: Smoothed target encoding (`pair_target_enc`) capturing city-pair rate levels.
3. **Equipment**: One-hot flags and ordinal codes for Dry Van, Flatbed, and Reefer.
4. **Temporal**: Day of week, month, quarter, day of year, cyclic sin/cos encodings, and days to nearest US holiday.
5. **Market Signals**: `market_index` and `quote_signal` are extracted and evaluated. Missing values in `market_index` are imputed with training medians. However, feature importance analysis reveals that route-level pricing and distance dominate model predictions; neither `quote_signal` nor `market_index` rank among the top 20 gain features.

## 5. Model Comparison & Results

Mean metrics across 3 CV folds (default parameters):

| Model | CV MAE ($) | CV RMSE ($) | CV MAPE (%) | CV R² |
| :--- | :---: | :---: | :---: | :---: |
| **CatBoost (Winner)** | **175.62** | **645.60** | **8.81** | **0.82** |
| LightGBM | 199.08 | 674.70 | 9.79 | 0.80 |
| XGBoost | 204.74 | 679.96 | 10.77 | 0.80 |
| Median Baseline | 1147.02 | 1567.54 | 68.04 | -0.07 |

**Winner**: CatBoost achieved the lowest RMSE on all three folds. Optuna tuning (30 trials) on a 15% temporal holdout optimized iterations, learning rate, tree depth, and regularization before retraining on all 48,000 rows.

### Error Analysis (Out-of-Fold Diagnostics)
- **Log-Log Calibration**: Predictions track the $y = x$ reference line tightly across standard rate tiers ($500 to $10,000).
- **Binned Rate Accuracy (5 Quantiles)**:
  - **Overall bucket accuracy**: `88.75%`
  - **Within-one-bucket accuracy**: `99.14%`
